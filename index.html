إعداد قاعدة البيانات

البرنامج محتاج مشروع Firebase مجاني عشان يحفظ بياناتك ويخليها متزامنة بين موبايلك ولابتوبك.

الخطوات

1. روح على console.firebase.google.com وسجل دخول بحساب Google.
2. اعمل Add project وسمّيه أي اسم (مثلاً: hassan-attendance).
3. من القائمة الجانبية: Build → Firestore Database → Create database — اختار Start in test mode.
4. من القائمة الجانبية: Build → Authentication → Get started → فعّل Anonymous من تبويب Sign-in method.
5. من الصفحة الرئيسية للمشروع، دوس على أيقونة الويب </> عشان تسجّل تطبيق ويب جديد.
6. هيديك كائن اسمه firebaseConfig — انسخه كله والصقه تحت.
د. حسن علي — العام العلمية
